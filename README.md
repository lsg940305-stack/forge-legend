# 포지 레전드 (Forge Legend)

재료를 사서 직접 도면을 그리고, 깎고, 다듬어 무기를 만드는 방치형 RPG예요.
만든 무기로 사냥하고, 강화하고, 다른 대장장이들과 전투력 랭킹을 겨뤄요.

## 받기

**👉 [최신 버전 APK 받기](https://github.com/lsg940305-stack/forge-legend/releases/latest/download/ForgeLegend.apk)**

예전 버전은 [Releases](https://github.com/lsg940305-stack/forge-legend/releases)에 있어요.

## 설치하는 법 (안드로이드)

1. 위 링크로 `ForgeLegend.apk`를 받아요.
2. 받은 파일을 눌러 열어요.
3. "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켜고 돌아와 **설치**를 눌러요.
4. 이미 깔려 있으면 그 위에 덮어 깔면 돼요. 기록은 그대로 남아요.

플레이 스토어 앱이 아니라서 "Play 프로텍트" 경고가 나올 수 있어요. 그때는 **무시하고 설치**를 눌러 주세요.

## 알아 두기

- 안드로이드 전용이에요.
- 아이디·비밀번호로 가입하면 기록이 서버에 저장돼서 폰을 바꿔도 이어서 할 수 있어요.
- 이 저장소에는 게임 파일(APK)만 올려요.
